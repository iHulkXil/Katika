KATIKA.BET — SPRINT 2A

Sprint 1 is complete and has been pushed to GitHub.

DO NOT modify the overall application architecture.

Current stack:

- React
- Vite
- TypeScript
- Tailwind CSS
- Wouter
- Lucide icons

This sprint ONLY adds Privy wallet authentication/connection to the existing application.

==================================================
SCOPE
==================================================

Implement Privy wallet connection.

DO NOT implement:

- betting
- wagering
- games
- demo credits
- deposits
- withdrawals
- real-money balances
- transactions
- rewards
- referrals
- AI

==================================================
PRIVY
==================================================

Install and configure the current Privy React SDK appropriate for this project.

Use:

PRIVY_APP_ID

The App ID may be exposed to the client as required by Privy's architecture.

Do NOT expose:

PRIVY_APP_SECRET

Do not request the App Secret in this sprint.

The App Secret will be handled later when we implement server-side verification.

Use the existing Replit Secret/environment-variable mechanism.

Do not hard-code the App ID.

==================================================
SESSION BEHAVIOR
==================================================

Verify:

- Wallet connection works.
- Disconnect works.
- Refreshing the page preserves the Privy session where supported.
- Navigation between pages preserves the connection.
- No authentication state is duplicated in multiple competing systems.

Use Privy's own client-side authentication state.

==================================================

Do NOT:

- expose PRIVY_APP_SECRET
- create a fake secret
- hard-code credentials
- place secrets in client code
- commit secrets to GitHub

Only use PRIVY_APP_ID for this sprint.
